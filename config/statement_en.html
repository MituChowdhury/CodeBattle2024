The Goal

You will start with 1000 coins. Spend the the coins wisefully to defend your base. Reach oppenents Base as many times as possible. You have 3 attributes to look out.
  • Score: Number of times your minions have reached the opponent's base.
  • Coins: Coins you have left for spending. Your coins will be updated on following scenerios-
    • Building an object : Coins will be deducted equal to the COST of the associated object.
    • Reaching opponent base : 60 coins will be rewarded
    • Destroying object: Associated object BOUNTY will be given to you.
    • Killing minion: For each of minion killed you will receive 25 coins
  • Death Count: Number of times your minions have died by oppenent's attack.

Winning coiditon

  • Player with maximum Score wins. In case of a tie
    • Player with maximum Coins left wins. In case of a tie
      • Player with minimum Death Count wins. In case of a tie
        • Its a tie :)

  Game Description

The game will run for 200 turns


The game is played on a map of size 20x15, the origin being in the top left corner. All the positions given as input will follow this coordinate system. You must adhere to this coordinate system while giving a build command.
You can hover on the game play to observe the coordinates and attributes of minions and objects in a frame.
The map itself is a grid of 20 x 15. Each block is called a 'Tile'. Every tile is divided into a 10 x 10 grid where every unit is called 'Subtile'.

Minions

Each player will have 5 minions they can't control. Each of them will respawn at its initial spawn position if it is killed or reaches the opponent base. Each minion of a player has an unique id associated with it. The id will remain unchanged throughout the whole game.

Spawn place

The players can choose the 5 y-coordinates for the spawn place on their minions. For red player the spawn x-coordinate is always 0, blue player's spawn x-coordinates is always 19. Everytime the minion is killed it will respawn at his initial spawn position.

Speed

The maximum number of subtiles a minion can cross in a single turn of the game.
Initially the speed is 10 which means a minion can walk through at most 10 subtiles.

Hitpoints

Unit of measurement representing an object's health or life. Hitpoints indicate how much damage a character or entity can withstand before being destroyed or killed.

Towers

Towers will automatically attack the opponent's minions if it is in range. Towers can be destroyed if attacked. A player can build two types of towers as follows:
  • Gun tower
    The gun tower attacks one minion at a time, reducing the hit point by its damage value. In case of multiple possible targets, it will always take the one closest to the player's own base.
  • Stun tower
    The stun tower does not cause any damage to the attackers. Instead, it will slow them down for the current turn. It targets all attackers in range, ignoring those which are already slowed down.
Towers can not be built on a tile where there is any object present other than a minion or a bomb . Once a tower is built on a tile , that tile is marked as blocked.

Spring Trap

Players can build spring trap that will relocate a minion instantly. The trap will affect any minion that steps onto it. Springs can not be attacked. Spring traps comes in with four variants -
  • North
  • South
  • East
  • West
They displace the minion RANGE amount tile in the respective directions.

If the tile where the minion lands contains a wall or a tower , the minion will die and the wall/tower will be destroyed. (Super minion!) If it lands on a tile that has built in obstacle, the minion will just die :(.

Spring trap can not be attacked by any means. But they have a short life span and will disappear after a certain number of turns. Spring does not block a tile. Springs can not be built on a tile where there is any object present other than a minion or a bomb

Bomb

Players can build bombs that will explode and deal damage to all the opponent's minions, towers and walls in its explosion ramge. if the bomb's position is (b_x, b_y), all the tiles (x, y) will deal damage that holds the condition abs(x-b_x) <= 2 && abs(y-b_y)<=2 . Thus a bomb explosion will be effective on an area of 5x5 tiles.

The bomb will explode after a certain number of turns. Bombs can not be attacked by any means. Bombs does not block a tile. It is allowed to build bomb on any tile. Players can build any other object on the same tile where the bomb is placed.

Wall

Players can build walls that will block the path of the minions. A wall will block a tile. Wall can not be built on a tile where there is any object present other than a minion or a bomb .

Turn

The game is played in turns. In each turn following events happen in sequence:
  1. Towers' / traps' / bombs' actions are carried out
  2. We send all the status of the game board to both of the player as input
  3. Players send their commands to the game
  4. Both of the player's commands are executed

Game Input

Initial Input

Line 1: playerId, either 0 (you defend the left side) or 1 (you defend the right side)


Line 2: width w &height h, the width and height of the map


Next, h lines will be printed each line containing w characters of either . or #. Where ‘.’ denotes no obstacle and ‘#’ denotes an indestructible obstacle.

Input in Each turn

First line will contain two integers, player_money and opponent_money , denoting remaining money of the player and remaining money of the opponent

Next line has two integer sc_p and sc_o denoting the score of the player and the score of the opponent

The next five lines contains 5 space separated integers id x y health speed describing the Id of the character, x and y coordinates of the player, health and status of the your characters.
** The above values will be -1 in case the has not been spawned yet.

The next five lines contains 5 space separated integers id x y health speed describing the Id of the character, x and y coordinates of the player, health and status of the characters of your opponent.
** The above values will be -1 in case the character has not been spawned yet.

Next line will contain an integer n_t denoting the total number of objects on the gameboard. Following n_t lines will contain the status of each object onn the map. Each line containing 10 space separated values in the following order-
type = string containing any of the values

  • GUN_TOWER
  • STUN_TOWER
  • SPRING_NORTH / SPRING_SOUTH / SPRING_EAST / SPRING_WEST
  • BOMB
  • WALL
id = Integer uniquely identifying the tower

owner = 0 / 1 (The player id)

position_x = x coordinate of the object

position_y = y coordinate of the object

**any of the following values will be -1 in case it does not apply

hitpoint = integer denoting health of the object

damage = integer denoting damage points of the object

range = integer denoting damage range of the object

cooldown = integer denoting number of frames between attacks performed by an object

bounty = how much coins a player will get for destroying this object


Game Output


   Initial output

At the 1st turn, the player needs to print 5 lines , one integer y in each line. These integers will be the y coordinates (row position) of the spawn positions. The characters will always spawn at these y-coordinates in case it gets killed or reaches the opponent base. The spawn x-coordinate is 0 for player 1 and 19 for player 2.

   Turn output

tarting from the 2nd turn the player must print 5 lines for each of their 5 characters. Each line must contain one of the following 3 commands-
  • go character_id

    The minion advances towards the opposition base. We taught the minions some basic DSA so that it can choose a destination tile that is closest to the opponent base as well as reachable from its current position. If there are more than one such tile , one is chosen at random. Then the minion randomly chooses one shortest path to the destination tile.

  • build character_id object_name pos_x pos_y

    The minion stops and builds the object at the specified position. The build takes one unit time.

    If both of the player tries to build an object at the same position at the same time , the player closer to his base will succeed. The other player's minion will just ignore the build command. (pos_x, pos_y) should be the coordinate of one of the 4-neighbours of the minion with id = character_id.

    In case of building a bomb the condition abs(pos_x-curr_x)<=3 and abs(pos_y-curr_y) <=3 must hold. where (curr_x,curr_y) is the current position of the minion with id = character_id

  • attack character_id direction

    The character stops and attacks at the specified direction from its current location. If there is an object at the target direction, it will deal damage. You can also attack any empty cell for fun.



Allowed namespace


object_name
  • GUN_TOWER
  • STUN_TOWER
  • SPRING_NORTH / SPRING_SOUTH / SPRING_EAST / SPRING_WEST
  • BOMB
  • WALL
direction
  • NORTH
  • SOUTH
  • EAST
  • WEST
character_id
    0,1,2,3 or 4

   Invalid Output condition

  • The player does not maintain the structure of the 3 commands mentioned above.
  • A character tries to build an object at a position where there is already an object. (Exception is while building a bomb)
  • A character tries to build object except his 4 neighbour.
  • A character tries to build or attack an object outside the map.
  • A character tries to build an object when the player does not have enough coins to build it.
  • A character can only choose one of his 4 neighbour tiles to build an object. Exception is bomb. See the bomb section for details.

    • In Case of invalid outputs the player's code will be terminated immediatly and the player will lose.
